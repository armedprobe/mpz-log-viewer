## Purpose

Даёт пользователям возможность экспортировать записи лога выбранного процесса МПЗ из просмотрщика в отдельный текстовый файл для обмена, архивирования или внешнего анализа.

## ADDED Requirements

### Requirement: Пользователь может экспортировать процесс в файл

Система ДОЛЖНА предоставлять возможность экспорта строк лога выбранного процесса в `.log`-файл.

#### Scenario: Экспорт через кнопку в тулбаре
- **WHEN** пользователь выделяет процесс (двойной клик) и нажимает кнопку экспорта в тулбаре
- **THEN** открывается диалог сохранения файла с именем по умолчанию `<имя_исходного_файла>-<PID>.log`
- **THEN** система записывает строки лога процесса в исходном порядке в выбранный файл
- **THEN** сохранённый файл является текстовым файлом с расширением `.log`, содержащим строки данного процесса

#### Scenario: Экспорт, когда процесс не выбран
- **WHEN** пользователь пытается экспортировать, но ни один процесс не выбран
- **THEN** опция экспорта ДОЛЖНА быть отключена или скрыта

#### Scenario: Отмена экспорта
- **WHEN** пользователь отменяет диалог сохранения файла
- **THEN** файл не создаётся и ошибка не показывается

### Requirement: Экспорт сохраняет исходные строки лога в порядке

Экспортированный файл ДОЛЖЕН содержать точные строки лога, принадлежащие выбранному процессу, в том же хронологическом порядке, в котором они встречаются в логе.

#### Scenario: Проверка содержимого экспорта
- **WHEN** пользователь экспортирует процесс
- **THEN** экспортированный файл содержит каждую строку лога, принадлежащую этому процессу
- **THEN** строки в экспортированном файле расположены в том же порядке, что и в исходном лог-файле

### Requirement: Имя файла по умолчанию

Система ДОЛЖНА предлагать осмысленное имя файла по умолчанию в диалоге сохранения.

#### Scenario: Формат имени по умолчанию
- **WHEN** исходный лог-файл называется `mpz.log`, а PID процесса — `12345`
- **THEN** диалог сохранения предзаполняет имя файла `mpz-12345.log`
