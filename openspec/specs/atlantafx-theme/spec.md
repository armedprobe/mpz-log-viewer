## Purpose

Обеспечивает единую современную визуальную тему приложения на базе AtlantaFX PrimerLight с минимальным кастомным CSS, использующим переменные цветовой системы AtlantaFX.

## Requirements

### Requirement: Приложение использует тему AtlantaFX PrimerLight

Система ДОЛЖНА применять тему AtlantaFX PrimerLight как пользовательский агентский стиль (user-agent stylesheet), заменяющий стандартную тему Modena.

#### Scenario: Запуск приложения с AtlantaFX
- **WHEN** приложение запускается
- **THEN** все стандартные JavaFX-контролы (Table, List, Button, Label, ScrollBar, Dialog и т.д.) отображаются в стиле PrimerLight
- **THEN** приложение визуально соответствует дизайн-системе GitHub Primer

### Requirement: Кастомный CSS минимален и использует переменные AtlantaFX

Система ДОЛЖНА использовать кастомный CSS (`app.css`) только для элементов компоновки, не покрываемых стандартными стилями AtlantaFX. Все цвета в кастомном CSS ДОЛЖНЫ задаваться через looked-up color variables AtlantaFX (`-color-*`).

#### Scenario: Кастомный CSS не содержит хардкод-цветов
- **WHEN** проверяется содержимое `app.css`
- **THEN** ни один цвет не задан в формате `#hex` (кроме полупрозрачного оверлея загрузки, не имеющего прямого аналога среди переменных)

#### Scenario: Стандартные контролы стилизуются AtlantaFX
- **WHEN** приложение отображает таблицу процессов, таблицу ошибок или список строк
- **THEN** выделение строк (`:selected`), наведение (`:hover`), заголовки колонок, скроллбары, шрифты — используют стили AtlantaFX без переопределения в `app.css`

### Requirement: Области с кодом используют моноширинный шрифт

Система ДОЛЖНА отображать содержимое области логов (raw-content-list) и таблицы ошибок (error-table) моноширинным шрифтом.

#### Scenario: Строки лога отображаются моноширинным шрифтом
- **WHEN** пользователь открывает лог-файл
- **THEN** строки в центральной панели отображаются шрифтом `"Consolas", "Courier New", monospace`

#### Scenario: Таблица ошибок отображается моноширинным шрифтом
- **WHEN** в логе найдены ошибки
- **THEN** текст ошибок в нижней панели отображается моноширинным шрифтом

### Requirement: Выделенный процесс подсвечивается псевдоклассом

Система ДОЛЖНА подсвечивать строку выделенного процесса в таблице процессов с помощью CSS-псевдокласса `:active-process`.

#### Scenario: Процесс выделен двойным кликом
- **WHEN** пользователь дважды кликает на процесс
- **THEN** строка процесса в таблице получает фоновый цвет `-color-accent-subtle` и жирное начертание
